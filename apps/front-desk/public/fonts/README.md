# GitLab fonts

These unmodified WOFF2 assets are from the official `@gitlab/fonts` package, version 1.3.1:

- `GitLabSans.woff2` — GitLab Sans, based on Inter.
- `GitLabMono.woff2` — GitLab Mono, based on JetBrains Mono.

The corresponding OFL-1.1 license files are included alongside the fonts. They are served locally so the interface does not depend on a third-party font request.

Sources: [GitLab font project](https://gitlab.com/gitlab-org/frontend/fonts), [font samples and downloads](https://gitlab-org.gitlab.io/frontend/fonts/), and [package version](https://www.npmjs.com/package/@gitlab/fonts/v/1.3.1).
